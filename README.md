# learn-ai-agent

A personal learning project: grow a tiny Python script into a deployed, RAG-powered AI agent — one concept at a time.

## Roadmap

| Stage | Adds | Topic learned |
|-------|------|---------------|
| 0 | Project skeleton (`uv`, `pyproject.toml`) | Python project structure |
| 1 | Call an LLM | LLM API basics |
| 2 | Manual agent loop | the agent loop |
| 3 | Web API | FastAPI |
| 4 | Deploy to AWS | EC2, security groups, systemd, SSM |
| 5 | Framework loop | LangChain |
| 6 | Stateful graph | LangGraph |
| 7 | Search my notes | vector embeddings + RAG |
| 8 | Expose tools | FastMCP |
| 9 | Full redeploy | S3, IAM, Bedrock |

## Run (Stage 0)

```bash
uv run assistant
```
